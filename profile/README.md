# The Kingfish Project

The Kingfish Project is an accountability journalism newsroom covering central Louisiana. Its reporting runs on one rule: every claim links to a document you can check yourself.

Read it at [kingfish.la](https://kingfish.la/). New stories also go out by [email](https://kingfish.la/newsletter/).

Send a tip or a document through [kingfish.la/tips](https://kingfish.la/tips/), and before you send anything sensitive, read [Contacting us and sending tips](https://kingfish.la/legal/privacy-policy/#contacting-us-and-sending-tips) in the Privacy Policy. To report an error in a story, follow the [Corrections Policy](https://kingfish.la/legal/ethics/#corrections). GitHub is not one of the newsroom's channels for tips or corrections.
