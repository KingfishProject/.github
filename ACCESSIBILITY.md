# Accessibility

The [Accessibility Statement](https://kingfish.la/legal/a11y/) on kingfish.la sets the site's conformance target and lists the barriers Kingfish knows about. It also says how Kingfish answers a report. Work on kingfish.la builds toward that target, [WCAG 2.2 Level AA](https://www.w3.org/TR/WCAG22/).

## Reporting a barrier

If anything on kingfish.la does not work for you, email [accessibility@kingfish.la](mailto:accessibility@kingfish.la), as the statement's [If something doesn't work for you](https://kingfish.la/legal/a11y/#if-something-doesnt-work-for-you) section asks. For a barrier in a repository's own code or documentation, open an issue in that repository. If the issue form is itself the barrier, or the repository takes no issues, email the same address instead.
