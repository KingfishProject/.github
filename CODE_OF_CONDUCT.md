# Code of conduct

The Kingfish Project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), as the code of conduct for every KingfishProject repository that has none of its own. The owner, the person who runs The Kingfish Project, is the community leader who enforces it.

## Reporting a problem

Report behavior that breaks the code of conduct by email to [editor@kingfish.la](mailto:editor@kingfish.la), not in an issue or a comment, which anyone can read in a public repository. Content that breaks GitHub's own rules can also be reported to GitHub, as [Reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) describes.
